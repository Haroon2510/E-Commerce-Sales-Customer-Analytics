# E-Commerce-Sales-Customer-Analytics
This is a detail project which gave a practical experience with the complete analytics workflow.

## Project Overview
This project demonstrates the design and implementation of an end-to-end Business Intelligence solution for an E-Commerce company using **Python, SQL Server, Power BI Desktop, Power BI Service, and Microsoft Fabric**.

The objective was to transform raw transactional data into meaningful business insights that enable management to monitor sales performance, profitability, customer behavior, product performance, and operational efficiency through interactive dashboards.


## Business Problem
The management team of an E-Commerce company was facing several challenges while analyzing business performance.

Business data was available in multiple transactional files, making it difficult to answer important business questions such as:

- Which product categories generate the highest revenue?
- Which products are most profitable?
- Which customers contribute the highest sales?
- Which payment methods are preferred by customers?
- Which marketing channels generate the maximum orders?
- How are monthly sales and profit trending?
- Which regions require additional business attention?
- What is the company's overall profitability?

The existing reporting process relied heavily on Excel spreadsheets, requiring manual effort to prepare reports every month. This resulted in:

- Delayed decision making
- Lack of centralized reporting
- Limited business visibility
- Time-consuming manual analysis
- Difficulty identifying business trends

The organization required an interactive Business Intelligence solution that would provide real-time analytical insights for management.


## Business Objectives
The primary objectives of this project were:

- Develop a centralized reporting solution.
- Monitor Sales and Profit performance.
- Analyze customer purchasing behavior.
- Track product and category performance.
- Identify high-value customers.
- Improve executive decision-making.
- Reduce manual reporting effort.
- Provide interactive self-service analytics.

## Proposed Solution
To address these challenges, an end-to-end Business Intelligence solution was designed.

The solution includes:

- Python-based synthetic dataset generation
- SQL Server database design
- Star Schema data model
- SQL Views for analytical reporting
- Power Query transformations
- DAX measures and KPIs
- Interactive Power BI dashboards
- Bookmark navigation
- Drill-through reports
- Tooltips
- Power BI Service deployment
- Dashboard and App publishing

This solution enables stakeholders to explore business data interactively while reducing dependency on manual reports.
